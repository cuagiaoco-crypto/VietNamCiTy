# B79 Street Life V15

Prototype web 3D chạy trực tiếp bằng `index.html`.

## Cách chạy
- Giải nén ZIP.
- Upload toàn bộ lên GitHub Pages / Vercel.
- File chính là `index.html`.

## Có gì trong V15
- Thành phố Việt Nam hư cấu 3D.
- Nhân vật, xe máy, NPC, xe cộ.
- Nhiệm vụ giao hàng.
- Ví tiền ảo localStorage.
- Ngày/đêm, ánh sáng, minimap.
- Không dùng Google Maps, không cờ bạc, không đổi thưởng.
